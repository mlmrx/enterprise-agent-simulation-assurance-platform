## Publishing rules

- Replace the `canonical_url` placeholder before syndication.
- Publish the canonical copy on `easap.dev` or the founder’s primary publication first.
- Preserve the truth boundary at the end of every article.
- Add the feature GIF indicated in each article’s front matter.
- Use descriptive alt text from `../02-platform-posts.md`.
- Link to the next article only after it is live.
- Do not add invented customer examples, performance claims, certifications, or partner logos.
