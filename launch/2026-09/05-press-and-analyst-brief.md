# EASAP press and analyst brief

## Release headline

**EASAP launches an open evidence system for deciding when enterprise AI agents are ready to act**

## Subheadline

The Apache-2.0 reference platform combines immediate release-readiness planning, verified public-agent testing, deterministic simulation, and portable decision evidence.

## Dateline release

**[CITY], [LAUNCH DATE]** — EASAP today announced the public availability of the Enterprise Agent Simulation and Assurance Platform, an open-source system that helps organizations evaluate whether an AI agent has earned the authority they plan to give it.

Unlike model benchmarks that evaluate a base model in isolation, EASAP treats the release candidate as a complete system: model, prompts, tools, memory, policy, connectors, runtime, data boundaries, and operating conditions. It converts those facts into executable scenarios, causal evidence, findings, and a bounded release posture.

Teams can use three working public capabilities immediately. The Agent Release Readiness Planner generates an inherent-risk tier, control gaps, scenario pack, accountable owners, approvals, and a machine-readable release gate without requiring an account. The verified public-agent connector tests authorized public HTTPS JSON endpoints only after file-based ownership verification and exports observed response evidence. The live workbench executes a deterministic synthetic procurement campaign and exposes the resulting measures, findings, digests, and decision.

“Organizations do not need another unqualified AI safety score,” said [FOUNDER NAME], creator of EASAP. “They need evidence tied to the exact agent they plan to release, the authority it will receive, the conditions under which it was tested, and the changes that make the decision expire. That is the boundary EASAP is designed to make inspectable.”

EASAP is designed to remain portable. Organizations can run the reference implementation locally, with Docker, on Kubernetes, or adapt its domain contracts to their preferred infrastructure. Authenticated or private agents can keep connectors, credentials, and data inside the enterprise boundary.

EASAP is a STANDARD reference implementation and not a certification body. It does not claim universal safety or the high-isolation controls required for every high-risk production workload. Its traceability, security, deployment, and production-gap documentation are public.

The platform is available at https://easap.dev. Source code is available under Apache-2.0 at https://github.com/mlmrx/enterprise-agent-simulation-assurance-platform.
